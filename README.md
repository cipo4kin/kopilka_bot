# 🪙 Копейка (@kopibabki_bot)

> Минималистичный трекер накоплений без рекламы кредиток, курсов крипты и душных нотаций. Только чистые цифры, живой дашборд и твой результат.

🚀 **Пощупать бота в Telegram:** [@kopibabki_bot](https://t.me/kopibabki_bot)

---

## 💡 Зачем этот проект?

Большинство финансовых приложений и ботов перегружены мусором: 50 категорий расходов, графики на пол-экрана, реклама партнерских карт и навязчивые советы, как правильно жить.

**«Копейка» сделана по принципу «открыл -> нажал две кнопки -> увидел прогресс»:**
- Одно интерактивное табло, которое обновляется на лету.
- Прогресс-бар мечты: от `0.0%` до `100.0%` (хоть на наушники, хоть на Сербло за 300к).
- Никакой каши в переписке: бот сам подтирает за собой сервисный мусор.

---

## 🔥 Что умеет под капотом

- **Живой дашборд (Zero Spam):** Бот не спамит новыми сообщениями на каждый чих. Дашборд обновляется на месте через `edit_message_text`, а служебные запросы ввода автоматически удаляются (`bot.delete_message`). Чат всегда чистый.
- **Ввод в одно касание:** Формат `40000 премия` или `250 такси` - сумма валидируется, парсится, лишние пробелы вычищаются, категория подставляется автоматически.
- **Два режима смены цели:**
  - `⚙️ Изменить цель` - если аппетиты выросли, но текущий накопленный баланс нужно сохранить.
  - `🚀 Новая мечта` - когда цель закрыта на 100%, бот сбрасывает историю и начинает копить с чистого листа.
- **Железная изоляция пользователей:** Все данные крутятся в SQLite с жесткой фильтрацией по `user_id`. Бот одновременно обслуживает меня, моих подруг и мою бабушку - ничьи балансы не перемешиваются.

## 🛠 Технический стек

- **Python 3.12**
- **aiogram 3.x:** асинхронный event loop, роутинг через CallbackQuery, FSM-стейты для многошагового ввода.
- **aiosqlite:** неблокирующие асинхронные SQL-запросы, расчет баланса через `COALESCE(SUM(amount), 0)`, транзакции и `INSERT OR REPLACE` для защиты от конфликтов `PRIMARY KEY`.
- **Инфраструктура:** боевой деплой в Docker-контейнере на облачном сервере в Германии (24/7 uptime, минимальный пинг до Telegram API, работа напрямую без прокси).

## 💻 Локальный запуск

Если хочешь поднять локально у себя:

```bash
# 1. Клонируем репу
git clone https://github.com/cipo4kin/kopeyka-bot.git
cd kopeyka-bot

# 2. Создаем и запускаем виртуальное окружение
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

# 3. Ставим зависимости
pip install -r requirements.txt

# 4. Настраиваем .env
cp .env.example .env
# вставляем свой BOT_TOKEN из @BotFather

# 5. Стартуем
python main.py
```
