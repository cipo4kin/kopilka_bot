# 🪙 Копейка - Telegram-бот для накоплений (@kopibabki_bot)

Минималистичный асинхронный Telegram-бот для постановки финансовых целей, учета личных доходов/расходов и визуализации прогресса накоплений в реальном времени.

> 🚀 **Живой бот в Telegram:** [@kopibabki_bot](https://t.me/kopibabki_bot)

---

## 🎯 Ключевые возможности

- **Живой интерактивный дашборд:** Единое информационное табло с визуальным прогресс-баром накоплений (`[████░░░░░░] 42.0%`).
- **Чистый чат (Zero Spam):** Автоматическое удаление сервисных запросов и служебных сообщений ввода через Telegram Bot API (`edit_message_text`, `delete_message`).
- **Учет операций в один клик:** Быстрое добавление доходов и расходов с категориями (например: `40000 премия` или `250 кофе`).
- **История транзакций:** Просмотр последних 5 финансовых операций с разделением по типам и категориям.
- **Гибкое управление целями:** 
  - Режим корректировки цели без потери текущего баланса (`edit_goal_keep`).
  - Режим «Новая мечта» с полным сбросом транзакций при достижении 100% цели (`new_goal_reset`).
- **Изоляция пользователей:** Поддержка множества независимых пользователей в единой базе данных SQLite (изоляция по `user_id`).

---

## 🛠 Стек технологий

- **Язык:** Python 3.12
- **Фреймворк:** [aiogram 3.x](https://github.com/aiogram/aiogram) (полностью асинхронная архитектура, FSM-стейты в памяти, CallbackQuery)
- **База данных:** [aiosqlite](https://github.com/omnilib/aiosqlite) (асинхронные неблокирующие SQL-запросы, транзакции, агрегации с `COALESCE`)
- **Конфигурация:** python-dotenv
- **Инфраструктура:** Docker-контейнер, развернут на облачном сервере в дата-центре в Германии (24/7 uptime).

## 🚀 Локальный запуск

1. **Клонировать репозиторий:**
   ```bash
   git clone https://github.com/cipo4kin/kopeyka-bot.git
   cd kopeyka-bot
   ```

2. **Создать и активировать виртуальное окружение:**
   ```bash
   python -m venv .venv
   # Windows:
   .venv\Scripts\activate
   # Linux/macOS:
   source .venv/bin/activate
   ```

3. **Установить зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Настроить переменные окружения:**
   Создайте файл `.env` на основе примера:
   ```env
   BOT_TOKEN=ваш_токен_от_BotFather
   PROXY_URL=http://127.0.0.1:10809  # Опционально (если нужен локальный прокси)
   ```

5. **Запустить бота:**
   ```bash
   python main.py
   ```
